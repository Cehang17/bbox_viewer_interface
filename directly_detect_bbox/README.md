# PDF & JSON Bounding Box Inspector

Bu arayüz PDF üzerinde Bounding Box görüntüleme/düzenleme, Türkçe odaklı cümle segmentasyonu, Draw Mode ile yeni kutu ekleme ve JSON dışa aktarma sağlar.

## Çalıştırma

```bash
cd directly_detect_bbox
python -m http.server 8080
```

Sonra `http://localhost:8080` açın.
